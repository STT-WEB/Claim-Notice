STT CLAIM v0.3.0 - ทั้งระบบ
============================

วิธีติดตั้ง (2 ขั้น)

1. ก๊อปไฟล์ทุกไฟล์ในโฟลเดอร์นี้ ไปทับในโฟลเดอร์
   ...\AI Inspection & Claim Program\deploy\
   (ทับได้เลย ของเดิมอยู่ใน git ครบ ถอยกลับได้)

2. เปิด Command Prompt ที่โฟลเดอร์ deploy แล้วพิมพ์
      node "ปรับปรุงไฟล์เดิม.js"
   (แก้ CLAIM-Hub.js ให้เข้ากับ v0.3.0 - เลื่อนเวอร์ชัน + เอาฟังก์ชันซ้ำออก)

3. กลับไปโฟลเดอร์โปรเจกต์ แล้วดับเบิลคลิก
      อัปเดตระบบเคลม.bat

4. เปิดเว็บ กด Ctrl+Shift+R แล้วดูป้ายมุมล่างหน้า login
   ต้องขึ้น  STT CLAIM HUB - v0.3.0

ไฟล์ในชุดนี้
  CLAIM-Inspect.js   โมดูลตรวจรับสินค้า (ใหม่)
  CLAIM-More.js      แท็บ 2-4 ของใบเคลม + บันทึกอัตโนมัติ + รายงาน (ใหม่)
  CLAIM-Index.html   เพิ่ม include ไฟล์หน้าเว็บใหม่
  styles.html        หน้าตาทั้งหมด
  js-core.html       หน้าแรก 3 กล่อง + ระบบบันทึกอัตโนมัติ
  js-claim.html      ใบเคลม 4 แท็บ + ระบบรูป
  js-inspect.html    หน้าตรวจรับ (ใหม่)
  js-report.html     รายงาน 4 หน้า (ใหม่)
  ปรับปรุงไฟล์เดิม.js  สคริปต์แก้ CLAIM-Hub.js
