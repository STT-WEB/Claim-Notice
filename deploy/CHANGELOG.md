# STT CLAIM — ประวัติการแก้ไขระบบ

> เรียงใหม่ → เก่า · **บรรทัดแรกคือเวอร์ชันจริงเสมอ**
> ไฟล์ .md ไม่ถูกอัปขึ้น Apps Script (clasp รับเฉพาะ .js .gs .html .json) ประวัติจึงอยู่ครบในเครื่อง

- **v0.1.2** (3 ก.ย. 2569) — เบียร์ทักว่า "ทำไมเข้าไม่ได้ เบียร์มีรหัสพนักงานและ PIN" → **ผมเดาผิด และการไปดูของจริงเจอของใหญ่กว่า**
  · **ผมผิด:** เบียร์มีทั้งรหัสพนักงาน (6100030) และ PIN 6 หลักในชีต **เข้าได้ปกติอยู่แล้ว** ผมสรุปเองโดยไม่เปิดชีตดู
  · **🚨 บั๊กจริงที่เจอตอนไปดู: 1 คนมีได้หลายสิทธิ์ แต่โค้ดผมคืนแค่ตัวเดียว**
    ในชีตมี 2 คนเขียนว่า `Sales / Production / QC` → `normRole_` เดิมคืนแค่ `QC` **สิทธิ์ขายกับผลิตหายเงียบ ๆ ไม่มี error**
    แก้: เพิ่ม `rolesOf_()` คืน**รายการสิทธิ์ทั้งหมด** · `requireAny_` เช็คแบบ "มีสิทธิ์ใดสิทธิ์หนึ่ง" · เพิ่ม role `SALES`
  · **ตรวจค่าจริงในชีตครบทั้ง 9 แบบ** และเอามาเป็นชุดทดสอบแทนค่าที่คิดขึ้นเอง:
    `ADMIN_EXEC` `EXEC` `Production` `PURCHASE` `QC` `STORE` `Design & Estimate` `Sales / Production / QC` และช่องว่าง
    (`ADMIN_EXEC`/`EXEC` → ADMIN ถูกต้องแล้ว · `Design & Estimate` → DESIGN)
  · ชุดทดสอบกันพัง **34 → 41 เคส** ผ่านหมด
  · **สิ่งที่ต้องแก้ในชีต (ไม่ใช่โค้ด)** — คนที่ active แต่ยังเข้าไม่ได้ 14 คน (PIN ว่าง) เช่น
    คุณแบล็ค · คุณประดิษฐ์ · จัดซื้อ 3 · แอดมินจัดซื้อ · และอีก 10 คน
    และ 3 คนที่ยังไม่ได้ใส่ `role for Claim` · **ตอนนี้เข้าได้จริง 24 คน จาก 40 แถว**

- **v0.1.1** (3 ก.ย. 2569) — แก้ที่พังจริงตอนติดตั้งครั้งแรก (ผมทำ .bat พลาดเอง 3 จุด)
  · **`clasp login --status` ใช้ไม่ได้กับ clasp รุ่นใหม่** (`error: unknown option '--status'`) → เอาออก
  · **git บน Windows ไม่มีชื่อผู้เขียน** → commit ไม่ผ่าน → push ไม่ขึ้น GitHub
    แก้: ตั้ง `git config user.name/user.email` เฉพาะ repo นี้ในตัว .bat เอง (ไม่ยุ่ง global ของเครื่อง)
  · **🚨 `clasp deploy` ไม่ใส่ `-i` = ได้ URL ใหม่ทุกครั้งที่อัปเดต** ลิงก์ที่แจกพนักงานจะตายทุกรอบ
    แก้: ล็อก deployment id ไว้ใน .bat → **ที่อยู่เว็บคงที่ตลอดไป**
  · เพิ่ม `.gitattributes` กันคำเตือน LF/CRLF และบังคับ .bat เป็น CRLF เสมอ
  · `อัปเดตระบบเคลม.bat` รัน **ชุดทดสอบกันพังด้วย** ไม่ใช่แค่ตรวจไวยากรณ์
  · **🚨 เบียร์กับพี่แบล็คเข้าเว็บไม่ได้** เพราะหน้า login บังคับรหัสพนักงาน+PIN แต่ 2 คนนี้ไม่มี PIN ในชีต
    แก้: เพิ่ม `loginByEmail()` — เปิดเว็บแล้วเช็คบัญชี Google ก่อน ถ้าเป็น 2 อีเมลบริษัทนี้เข้าได้เลย
    คนอื่นได้ GUEST เสมอ = ยังต้องใส่ PIN (ปลอดภัยเท่าเดิม ตามบทเรียน NOVA v0.27.2)
