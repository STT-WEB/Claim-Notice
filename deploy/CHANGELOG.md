- **v0.5.0** (4 ก.ย. 2569) — **ขั้นตอนงานและหน้าที่** (เบียร์ออกแบบเอง ผมไปเทียบกับ NOVA มาก่อนทำ)

  **สิ่งที่ไปตรวจก่อนลงมือ:** อ่านโค้ด NOVA ทั้งชุด — **NOVA ไม่มีระบบขั้นตอน**
  มันแบ่งด้วย**เมนูรายบทบาท** (`ITEMROLE`) + ด่านอนุมัติ 3 ด่านที่เขียนแยกกันคนละชุด
  (BOM · ล็อกต้นทุน · Final KOM) ส่วนใครกรอกคอลัมน์ไหนใช้**ธรรมเนียม**ล้วน ๆ ไม่มีตารางสิทธิ์
  → งานเคลมเป็น "เอกสารใบเดียวที่ส่งต่อกันเป็นทอด" จึงเหมาะกับระบบขั้นตอนจริง ๆ ไม่ใช่แยกเมนู

  **6 ขั้นตอน** (`CLAIM-Flow.js` — ไฟล์ใหม่)
  1. **แจ้งเคลม** — Production / Sales / QC / Design : ข้อมูลรถ + รายการที่เคลม + รูป
  2. **สโตร์เติมข้อมูล** — เลขใบส่งมอบ · PO · Supplier
  3. **จัดซื้อตรวจข้อมูล** — Accept หรือ ตีกลับ
  4. **ส่ง Supplier · รอคำตอบ** — จัดซื้อ (คำตอบ Supplier + ใบเรียกเก็บ)
  5. **รับของกลับ + QC** — QC / Production
  6. **ปิดงานแล้ว**

  **หลักที่เบียร์วางไว้ ทำครบทุกข้อ**
  · **ทุกคนเห็นข้อมูลทั้งหมด** ไม่มีใครถูกซ่อนอะไร — ต่างจาก NOVA ที่แยกเมนูแล้วมองไม่เห็นกัน
  · **ทำงานแทนกันไม่ได้** — ช่องที่ไม่ใช่ขั้นของคุณเป็นสีเทา เอาเมาส์ชี้บอกเหตุผลว่าเป็นของใคร
  · **สโตร์กับจัดซื้อช่วยกันได้** — 2 บทบาทนี้แก้ช่องของกันและกันได้ (เบียร์สั่งไว้ชัด)
  · **JMC แก้ได้ทุกเมื่อ** โดยคนเปิดใบ เพราะ "มันจะมาทีหลังเลย" ไม่ต้องรอถึงขั้นไหน
  · เช็คสิทธิ์**ทั้งหน้าจอและหลังบ้าน** — หน้าจอกันคนพลาด หลังบ้านกันคนตั้งใจ

  **ตีกลับ** — จัดซื้อเลือกได้ว่าส่งกลับหาสโตร์หรือคนเปิดใบ · **บังคับใส่เหตุผล**
  (ไม่งั้นคนรับไม่รู้ว่าต้องแก้อะไร) · เหตุผลขึ้นเป็นแถบแดงบนหัวเอกสาร + เด้ง LINE

  **กันส่งงานที่ยังไม่ครบ** — `claimMissing_()` บอกตั้งแต่ก่อนกดว่าขาดอะไร
  (ขั้น 1 = เลขจ๊อบ/รายการ/รูป · ขั้น 2 = PO/Supplier รายข้อ) ปุ่มส่งต่อจะกดไม่ได้จนกว่าจะครบ

  **LINE** — ยกวิธีจาก NOVA มาทั้งดุ้น: **Messaging API แบบ push**
  (LINE Notify ปิดบริการไปแล้ว 31 มี.ค. 2568 ใช้ไม่ได้อีก · NOVA ย้ายมาแล้ว เราใช้ตาม)
  แยกกลุ่มตามแผนกได้: `LINE_GROUP_PRODUCTION / STORE / PURCHASE / QC` ไม่ตั้งก็ใช้ `LINE_GROUP` กลาง
  **ยังไม่ตั้งค่า = ระบบทำงานปกติทุกอย่าง แค่ไม่ส่ง LINE** ไม่ error ไม่ค้าง · มีฟังก์ชัน `testLine()` ให้กดทดสอบ

  **เปลี่ยนชื่อ "พื้นที่" → "สถานที่ผลิต"** ทั้งระบบตามที่เบียร์แก้ (13 จุด ทั้งหลังบ้านและหน้าจอ)

  **คอลัมน์ภาษาอังกฤษโผล่เฉพาะงานต่างประเทศ** — งานในประเทศไม่มีคอลัมน์ EN และไม่มีปุ่มแปลเลย
  ทั้งใบเคลมและใบตรวจรับ · สลับสถานที่ผลิตกลางคัน ตารางสร้างใหม่โดย**ไม่ทำข้อมูลที่กรอกไว้หาย**

  · **กับดักที่ดักไว้ทัน:** เดิมโค้ดใช้ `HDR_CLAIM.length` เป็น "คอลัมน์แก้ไขล่าสุด"
    พอเพิ่ม 6 คอลัมน์ใหม่ ตัวเลขนั้นจะเลื่อนไปทับคอลัมน์ใหม่ = **เขียนผิดช่องแบบเงียบ ๆ**
    → เปลี่ยนมาใช้ `colOf_('แก้ไขล่าสุด')` หาจากชื่อหัวตาราง และ `ensureCols_()` เติมคอลัมน์ให้ชีตเก่าเองโดยไม่แตะข้อมูลเดิม
  · **วิธีตรวจ:** เปิดใบเคลมด้วยสิทธิ์สโตร์ในเบราว์เซอร์จริง → ช่องของขั้น 1 **ล็อกจริง 15 ช่อง**
    ช่องในตาราง **ล็อกจริง 9 ช่อง** · แถบขั้นตอนชี้ขั้น 2 ถูกต้อง · เหตุผลตีกลับขึ้น · ปุ่มส่งต่อกดไม่ได้เพราะยังขาด PO
    สลับในประเทศ↔ต่างประเทศ คอลัมน์ EN หาย/มา ถูกต้อง · **0 JavaScript error**
